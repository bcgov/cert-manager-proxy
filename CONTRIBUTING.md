# How to Contribute

## Git workflow

1. Branch off a fresh `main`.
2. Use a type prefix on the branch (`feat/`, `fix/`, `chore/`, …).
3. Open a pull request against `main`.

## Conventional Commits

PR titles (and squash-merge commit messages) must follow
[Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/),
for example `feat: allow webhook DNS-01 solvers` or `fix: reject empty domain`.

The PR Validate workflow checks the title, not every commit on the branch.
